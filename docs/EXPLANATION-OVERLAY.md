## Implemented contract and current limits

`SceneNode.spatial3D` carries typed groups, boxes, spheres, cylinders, toruses and bounded partial/full tubes. Transforms use right-handed world space, +Y up, and local `T * Rz * Ry * Rx * S`. Labels reference a stable target part and retain the model's canonical target-local anchor unchanged. A separate host-owned attachment resolves that hint to a visible triangle on the target or its descendant; native camera projection of the resolved world point supplies the leader endpoint. The host chooses materials and native geometry. Model-generated code, textures, URLs and imported meshes are not accepted.

Documents containing typed spatial fields encode as `opencompanion.scene/2`; existing 2D documents retain version 1 and their meaning. Typed payloads cannot masquerade as version 1. Node/geometry/triangle budgets apply before native allocation. Local values, composed world transforms, primitive bounds and label anchors are checked, including at animation time. Scene patches are atomic; converting an existing part between legacy and typed domains requires explicit remove/create.

Normal NDJSON scene units may include bounded static `connectors`: native code resolves target-local endpoints and compiles an ordinary cylinder in the same atomic transaction. The recipe is not persisted or continuously followed. It does not choose a scientific part, repair supplied mesh geometry or create an animated joint. Existing revision/generation and geometry budgets remain mandatory; the structured experimental formats do not gain this field. [Contract, public trials and limits](SPATIAL-CONNECTORS.md).

Historical `ac38f823` kept its visual window wholly click-through, transparent, nonactivating and excluded from capture, with a bounded **× Clear** companion. Current `cc6bcd3` stays passive by default but reserves the bounded whole visual panel during explicit Option-only arming/dragging, then returns to click-through. This claims no transparent-pixel mouse holes; the Clear pill retains independent ownership. Clear stops the current response, unmounts both windows and retains the document and transcript. A per-presentation lease prevents an old Clear action affecting a renewed presentation. Sleep and session activity have independent gates. A removed display dismisses the presentation rather than moving it to another display.

New physical parts fade in locally. Anchored overlay labels reveal one bounded word group at a time using the existing 0.22-second cursor cadence; excess frame delay never creates a catch-up burst. Canonical full text supplies stable layout bounds. Changed label/document ownership resets presentation; a new generation settles prior labels. Reduce Motion reveals text immediately. The display clock also handles labels when scene animation is paused, and stops after settlement or dismissal. Native tests explicitly exercise full motion and Reduce Motion through an immutable per-view policy; production defaults to the live macOS preference. This avoids inheriting a CI desktop preference as a pacing-test assumption. This is local pacing, not speech synchronization or measured display FPS.

Anchored overlay labels use the built-in `ChalkboardSE-Regular` font when available, with a system-font fallback. Native/CoreText measurement matches the drawing font. ## Acceptance before claiming this slice complete

1. Extend the real-provider motor plus one held-out 3D case to at least two held-out concepts, including a 2D explanation. Retain typed validation, progressive arrival, independent content checks and final native visual inspection.
2. Inspect actual native pixels over contrasting, nonuniform backgrounds. Verify the intended transparency, visible bounds, controls, multi-display placement and display scaling without a desktop-sized invisible input blocker.
3. Exercise Notebook orbit with real input; verify part-anchor projection, label readability, Clear, keyboard/Accessibility access and Reduce Motion. Any future interactive overlay needs independent input-routing acceptance. Record supported zoom or selection separately rather than inferring it from the reference.
4. Test cancellation during reveal, a replacement turn, Clear followed by late output, and speech finishing before the explanation is dismissed. Confirm ordinary conversation/guidance does not open Notebook unnecessarily and deliberate Notebook editing still works.
5. Record capture/provider/reveal/audio clocks separately if measured. Verify actual narration and interruption independently before claiming speech alignment, latency or animation-performance parity.
